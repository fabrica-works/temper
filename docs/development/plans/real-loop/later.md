# real-loop: later

What the designs name but this plan does not do, and when it should be
done. The first rows are what this plan's questions and decisions left
for later. The rows from the real-git bridge on are what the real-loop
world (temper's `testing.md`, 2.4) still lacks to cover the rest of
temper once this plan has built it with area 1's stories: each names the
piece missing and what it would cover, so that a real-loop plan after
this one can start from them. They carry the tools plan's `later.md`
rows forward, with skein's forge peer where those name the fake forge's
host (decisions.md, 1). Each real-loop story they name is smoke, one
path per feature; a case they name below the real loop is tested in the
lower world that owns it (temper's `testing.md`, 2.4; ruling 130).
