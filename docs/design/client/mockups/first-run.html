A Forgejo elsewhere · Restart needed

For a forge at forge.example, add this entry to application.forges in ~/.config/temper/temper.json. Replace the example host with yours; use an unused forge number.

{
  "number": 4,
  "kind": "forgejo",
  "api": {"host": "forge.example", "port": 443},
  "transport": {"tls": {
    "server_name": "forge.example", "trust": null
  }},
  "git": "https://forge.example",
  "web": null,
  "log_origins": null
}

Add its git identity to application.identities, using an unused identity number and the same forge number:

{
  "number": 4, "forge": 4, "login": null,
  "author": {
    "name": "temper",
    "email": "temper-bot@forge.example"
  }
}

Stop and start temper box. Return to Forges to connect with the bot’s API and git tokens, or choose “Connect as its admin”. Keep credentials out of the configuration.

Mockup: connections and downloads are simulated. Nothing is sent or written to your configuration.
