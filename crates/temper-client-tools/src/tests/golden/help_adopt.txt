Adopt a repository
Result: adopt
  project: Project name or number
  forge: Forge number, within u16
  owner: Repository owner
  name: Repository name
  landing: Landing branch
  role: Repository role
  prefix: Branch prefix
  no-home: Do not make the repository home
  no-ci: Do not use forge CI
  check: Gate number
